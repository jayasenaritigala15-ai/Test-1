# 🎧 hpskw PRO DJ System

Advanced browser-based DJ system with professional features, AI assistance, and a unique cat ear visualizer.

## ✨ Features

### 🎚️ Dual Decks
- Independent playback with waveforms
- Pitch control (±8%)
- 3-band EQ (Low, Mid, High)
- Filter control
- Volume and VU meters
- 8 hot cue points per deck

### 🔄 Advanced Controls
- Loop (1, 2, 4, 8, 16 beats)
- Reverse playback
- Key shifting
- BPM sync
- Crossfader with A/C/B presets

### 🎛️ Mixer
- Master volume
- Bass boost
- Karaoke mode
- Harmonic boost
- Limiter/compressor

### 🎶 Effects
- 20+ effects: Delay, Reverb, Flanger, Phaser, Chorus, Distort, etc.
- Wet/Dry mix control

### 🔊 Sampler
- 24 built-in sounds
- Keyboard shortcuts (Alt+keys)
- Visual feedback

### 🤖 AI Features
- Genre detection
- Mood analysis
- Beat matching
- Smart transitions
- Energy detection
- Cue point prediction
- Voice DJ announcements
- Playlist recommendations

### 🎤 Voice Control
- Sinhala and English support
- Commands: play, stop, bass, next, loop, horn, drop, sync

### 📋 Playlist
- Add, save, clear, shuffle
- Next track auto-play

### 🏆 XP & Achievements
- Level up system
- 14+ achievements
- Progress tracking

### 💾 Session Management
- Export/Import session data
- History tracking

### 🎨 Visualizer
- Cat ear circular spectrum
- Particle effects
- Real-time frequency analysis

## 🚀 Quick Start

1. Clone or download the files
2. Open `index.html` in a modern browser
3. Click to start
4. Load audio files using the "Load" buttons
5. Start mixing!

## ⌨️ Keyboard Shortcuts

| Key | Action |
|-----|--------|
| Q | Toggle Deck A |
| W | Toggle Deck B |
| Space | Center crossfader |
| R | Toggle recording |
| Z/X | Deck A pitch down/up |
| ,/. | Deck B pitch down/up |
| 1-8 | Hot cues (Deck A) |
| Shift+1-8 | Hot cues (Deck B) |
| Ctrl+P | Toggle recording |
| Alt+1-8,Q,M | Sampler pads |
